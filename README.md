**双击 `适中-H5原稿.html` 或 `index.html` 即可。** 两个文件都是轻量入口。请把同目录的 JS、CSS、`data/` 和 `assets/` 一起保留或部署，不能只复制 HTML。页面不依赖外站图片、在线 API、安装依赖或构建工具。

## 通讯聊天工具（既有功能）

- 聊天输入栏支持文字、表情与语音切换；“＋”面板提供相册、视频通话、语音通话、文件、红包、转账、位置、名片及礼物入口。
- 相册支持 JPG、PNG、WebP，单张最大 **5MB**；文件附件单个最大 **20MB**。消息内可查看照片、播放语音和保存附件。
- 实际语音录制需通过 **HTTPS** 访问并允许麦克风，最长 **60 秒**。不支持录音或未授权时可发送 **6 秒示例语音**，通过浏览器语音朗读播放，不是真人录音。
- 好友单独会话可体验语音／视频通话、接听等待、计时、按钮状态、挂断与通话记录；画面使用照片模拟，**不连接真人、不采集真实通话音视频**。群组、商家与客服会话不提供这类通话。
- 红包与转账使用本地 RM 演示余额：确认发送时将扣款、消息与账单作为一个保存操作；保存失败回滚。消息详情可体验领取与退款，状态变化不会重复扣款或重复退款，不产生真实支付。群聊普通红包供 1 人领取，转账需进入好友单独会话。
- 位置可填写地址、选常用地点或在允许定位后取得坐标；位置卡使用示意图，详情可打开外部地图。名片可进入对应好友资料。
- 照片、录音和文件仅保存在当前浏览器的 **IndexedDB**；消息元数据、文字和演示状态保存在 **localStorage**。导出的 JSON **不包含媒体文件**，换设备或清理浏览器数据后不能靠 JSON 恢复附件。
- 部署必须上传 `chat-tools.js` 与 `chat-tools.css`；脚本位于 `private-room.js` 之后，`layout.css` 仍是最后加载的样式。本轮复用现有静态图片。

## 原稿体验说明

- 这是前端交互原稿，没有真实后台、支付、即时通讯或音视频推流。
- 人物名称、商家、价格、评价、距离与观看人数为演示数据。
- 图片来自免费图库，人物照片不表示照片中的人注册了平台或为产品背书。
- 聊天、表单、预约、动态与个人偏好只保存在当前浏览器。不同浏览器、文件路径和访问地址的数据相互独立。
- 可在「我的 → 设置」导出或重置演示数据；导出 JSON 仅含消息元数据和演示状态，不含 IndexedDB 中的照片、录音或文件。
- 既有头像、动态等上传入口支持 JPG、PNG、WebP，每张不超过 1.5MB；聊天相册单张上限为 5MB，聊天文件附件上限为 20MB。存储不足时会提示失败；需要保留的媒体请在消息详情中单独保存。
- 「语言与地区」保存沟通语言偏好，界面语言目前为简体中文。
