# 直播礼物图标与特效来源说明

核实日期：2026-09-27。本地图片与自制动效已经接入 H5 直播间，未连接抖音账号、支付或真实直播后台。

## 当前实现

`live-data.js` 定义 34 款礼物：16 款 Fluent 素材礼物和 18 款官方公开文档图标。`live-room.js` 提供礼物列表、价格、数量、体验金豆、赠送记录和 VIP 展示；`live-effects.js` / `live-effects.css` 实现 7 类自制特效（爱心、花瓣、礼花、跑车、火箭、皇冠、星河）。这些动画不是抖音原版动画文件。

适中界面使用自行设定的“体验金豆”价格；部分数值参考公开表格，但不表示抖币兑换或 RM 汇率。私人装扮商城继续采用自己的 RM 价格。预览不扣金豆，赠送在本地保存成功后扣除；免费体验额度不连接支付。

## 本次取得的素材

- `assets/live-gifts/douyin-*.png`：18 张抖音公开开发文档内的礼物图标，最长边 256px，保留比例与透明通道；合计 1,024,320 字节。它们是静态图标，不是原版礼物动画包。
- `assets/live-gifts/fluent-red-heart.png`、`fluent-party-popper.png`：另补 2 张 Microsoft Fluent Emoji 3D 的小心心、礼花筒，MIT 许可；20 张图片合计 1,091,392 字节。
- `catalog.json`：18 款官方图标的简洁 UI 清单，含本地路径、官方加密 ID、公开抖币标价和许可状态。
- `reusable-fallbacks.json`：2 张新增 Fluent 图标及原有 12 张素材的复用路径，可覆盖鲜花、爱心、跑车、气球等常用示例；这些图标不标为抖音原版。
- `sources.json`：各图片公开 URL、原图格式/尺寸/哈希、本地图尺寸/哈希、处理方式与适用范围。原始大图和抓取的公开页面仅留在工作目录，不必加入发布包。

18 款图标均从[抖音开放平台《直播间礼物互动能力》](https://partner.open-douyin.com/docs/resource/zh-CN/interaction/jierushuoming/hudongshuju/liwushuju)第四节表格逐项提取，没有访问登录后的资源或直播间私有接口。

## 官方礼物信息接口

[`tt.getLiveRoomGiftPool`](https://developer.open-douyin.com/docs/resource/zh-CN/live-interactive-tools/development/js-api/live-streaming-capability/tt-live-room-gifts) 在直播互动工具运行环境内返回礼物图标、名称、价值和加密 ID。文档要求先创建插件并申请“获取礼物互动数据”权限，且不支持沙盒；缺少已创建的玩法卡片也有专门错误码。它不是独立静态 H5 可匿名调用的全网礼物素材接口。

## PAG、SVGA：播放器与动画文件分别确认

- [Tencent/libpag](https://github.com/Tencent/libpag) 是 PAG 文件的渲染库，支持 Web；PAG 文件可由 After Effects 配合 PAGExporter 制作导出。[库许可](https://github.com/Tencent/libpag/blob/main/LICENSE.txt)为 Apache-2.0，并单列第三方组件许可。库本身不附带“任意抖音礼物均可使用”的权利。
- [SVGAPlayer-Web](https://github.com/svga/SVGAPlayer-Web) 用于播放 SVGA 动画，[源码许可](https://github.com/svga/SVGAPlayer-Web/blob/master/LICENSE)为 Apache-2.0。该仓库已于 2023-02-06 归档，README 明确停止维护；引入前应实际测试目标浏览器。
- `.pag` / `.svga` 是动画文件；文件里的美术、字体、音频以及作者交付范围要分别有来源。取得播放器源码许可，不会自动获得第三方动画或截图角色的许可。
- 当前 PNG 可以配合自制 CSS/Canvas 粒子、轨迹、缩放和弹出动效进行 H5 演示。此类实现应描述为自制演示动效；若后续取得独立授权的动画，再按需加载对应播放器和文件。本次没有新增播放器依赖。

## UI 读取建议

官方素材清单和 Fluent 复用清单分开，避免误标来源。`image` 是传给既有 `asset()` 的相对路径，如 `live-gifts/douyin-donut.png`；礼物列表图片继续按需加载。首屏不必预载全部 20 张图片；缩放时保留透明边缘，使用 `object-fit: contain`。

新直播模块独立提供金豆赠礼；原有 RM 礼物库存和装扮功能继续使用原模块。关闭或切换直播间时停止评论计时器和特效，素材从本地目录读取。
