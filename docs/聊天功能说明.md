# 适中聊天功能说明

本文列出 App 聊天的全部功能、在后台「系统配置」中对应的设置项，以及服务端接口。设置项在后台 **系统配置 → 聊天 / 聊天功能（表情回应、删除、定时、相册、视频）/ 红包与转账 / 语音·视频通话 / 客服工作台**，也嵌在 **客服工作台 → 聊天与客服设置** 页面。标注「公开」的设置会随启动数据发给 App，修改后 App 刷新即生效。

代码位置：`chat-tools.js`（聊天界面主体、红包转账、通话等）、`chat-tg.js` / `chat-tg.css`（Telegram 风格功能）、`chat-tg-video.js`（视频播放器）、`locales/chat-tg.js`（中英文文案）；服务端 `server/Shizhong.Api/Modules/Messaging`（`MessagingApi.cs`、`ChatFeaturesApi.cs`、`ChatFeatures.cs`、`ChatRules.cs`、`ChatTimerWorker.cs` 等）；数据库迁移 `server/db/migrations/0301_messaging.sql`、`0302_chat_telegram.sql`。

## 二、长按菜单（Telegram 风格）

长按消息（手机）、右键（电脑）或键盘 ContextMenu / Shift+F10 打开：

- 背景模糊，按住的消息被“抬起”显示，上方是圆角表情条，下方是毛玻璃菜单。
- **表情条**：7 个快捷表情 + ⌄ 按钮展开全部可用表情；点一下即回应。
- **菜单头**：自己的消息显示勾和时间，私聊已读时显示“✓✓ 09/25/26 21:02 已读”（精确到对方读到这条消息的时间）；群聊显示“查看已读成员”，点开可看已读成员和表情回应列表；别人的消息显示发送时间。
- **菜单项**（按消息类型和是谁的消息显示）：
  回复、拷贝（文字 / 说明文字）、编辑（自己的文字或图片视频说明，在时限内）、置顶 / 取消置顶、转发、保存（图片、视频、相册、文件）、举报（别人的消息）、删除（红色；开启了自动删除的消息下方显示“🕐 N 天后自动删除”）、分隔线、选择（多选）。
- 发送中的消息只显示“取消发送”。

| 实时 | 双方 / 全体成员实时更新（`chat:reactions`） | — |
| 通知 | “X 回应了你的消息”静默通知，同一会话在间隔内只通知一次，不刷屏 | `chat.reactionNotice`、`chat.reactionNoticeMinutes` |

## 四、删除（仅为我删除 / 双向删除）

- 删除对话框：私聊显示“同时为 {对方} 删除”“仅为我删除”；群聊显示“为所有人删除”“仅为我删除”。
- 双向删除实时同步，默认**不留“撤回了一条消息”提示**（同 Telegram）。
- 可以双向删除的消息：
  - 自己发的消息：在时限内（默认不限时，同 Telegram）；
  - 私聊中对方发的消息：默认允许（同 Telegram），可关闭；
  - 群聊：群主和管理员可以删除任何人的消息（管理）；
  - 红包、转账、礼物、系统消息永远不能双向删除（账本和礼物记录依赖它们）。
- “仅为我删除”可撤销（提示条上的“撤销”）。
- 被删除的消息在服务端保留（`DeletedAt`），后台客服工作台仍可看到并标注“已删除”。
- 被删消息的文件：只有在没有其他消息（例如转发的副本）使用时才会删除。
- 离线演示模式：“同时为对方删除”即旧版撤回（2 分钟内自己的消息，显示“你撤回了一条消息 · 重新编辑”）。

| 设置项 | 默认 | 说明 |
|---|---|---|
| `chat.deleteForEveryoneSeconds` | 0（不限） | 自己的消息多少秒内可双向删除（公开） |
| `chat.deletePeerMessages` | 开 | 私聊可以把对方的消息也从双方删除（公开） |
| `chat.deleteNotice` | 关 | 开启后双向删除会留下“撤回了一条消息”提示（相当于旧版撤回）（公开） |

## 五、消息定时删除（自动删除）

- 入口：聊天标题栏 ⋯ 菜单 → **消息自动删除**：关闭 / 1 天 / 1 周 / 1 个月 / 自定义（分钟到 1 年，受最短时间限制）。
- 私聊双方都可以设置；群聊只有群主和管理员可以设置；客服和商家会话不可设置。
- 设置后聊天里出现系统消息“X 设置了消息在 1 周后自动删除”，标题栏显示小计时器图标。
- **只作用于设置之后发送的消息**；每条消息带到期时间，长按菜单的“删除”下显示“🕐 N 天后自动删除”。
- 服务端后台任务（`ChatTimerWorker`）定期删除到期消息，双方实时消失（`chat:deleted`）；红包、转账、礼物和系统消息不会被自动删除。

| 设置项 | 默认 | 说明 |
|---|---|---|
| `chat.autoDeleteEnabled` | 开 | 关闭后不能再设置，已设置的计时器也不再作用于新消息（公开） |
| `chat.autoDeleteMinMinutes` | 60 | 自定义时间最短分钟数（测试时可设为 1）（公开） |
| `chat.autoDeleteCheckSeconds` | 15 | 自动删除 / 定时发送的检查间隔 |

## 六、多选

- 长按 → 选择，或标题栏 ⋯ → 选择消息。进入后每条消息左侧出现圆形勾选框，顶部显示“已选择 N 条”和“取消”，底部是“转发”和“删除”。
- **转发**：按聊天中的顺序转发为多条独立消息，每条带“转发自 X”，可同时选择多个聊天（最多 20 个）。
- **删除**：全部可双向删除时提供“同时为对方删除 / 为所有人删除”。

## 七、相册（多图 / 多视频 + 说明）

- “+” → 相册：可同时选择照片和视频，打开 Telegram 风格的预览：网格、每项右上角 × 移除、“继续添加”、说明输入框、**压缩图片**开关（关闭则按原文件逐个作为文件发送）。
- 发送后成为一条相册消息，按 Telegram 拼图排版，说明显示在下方；上传时显示进度环，可取消。
- 点开进入全屏查看器：左右滑动、双指 / 双击缩放、滚轮缩放、“2 / 5”计数、保存、转发、下滑关闭。

| 设置项 | 默认 | 说明 |
|---|---|---|
| `chat.albumMax` | 10 | 每个相册最多项数，超出自动拆成多条（公开） |
| `chat.captionMax` | 1024 | 说明最多字数（公开） |

## 八、文件

- “+” → 文件：任意类型（受大小限制），Telegram 风格文件气泡：按类型着色的圆形图标（PDF 红、文档蓝、表格绿、压缩包黄…）、文件名、大小。
- 上传时圆环显示进度，点 × 取消；下载时圆环显示下载进度，完成后可“打开”或“保存到设备”。
- 服务端下载一律作为附件、`nosniff` 并禁止脚本。

| 设置项 | 默认 | 说明 |
|---|---|---|
| `chat.fileMaxMb` | 20 | 聊天文件最大 MB（公开） |
| `chat.fileAnyType` | 开 | 聊天文件允许任意类型；关闭则按 `upload.allowedFileTypes` |
| `upload.fileMaxMb`、`upload.allowedFileTypes` | 20 / 列表 | 平台上传限制 |

## 九、视频

- 选择视频后在本机用画布截取第一帧作为封面，并读取时长，一起上传；上传时显示进度。
- 气泡显示封面、时长角标；**短视频在屏幕内时静音自动循环播放**（同 Telegram）。
- 全屏播放器：点按显示 / 隐藏控制栏，播放 / 暂停，进度条（显示已缓冲部分）和时间，倍速 0.5–2×，静音，填充 / 旋转，保存、转发，支持时显示画中画按钮，下滑关闭；键盘：空格、←/→ 5 秒、M、F。
- 服务端校验文件头（MP4 / MOV / WebM），类型以文件内容为准；`/api/media/{id}` 支持 HTTP Range（206），按需分段从数据库读取，拖动进度条在 IIS / Cloudflare 后面也能正常工作。
- **视频消息（圆形）**：“+” → 视频消息，打开前置摄像头圆形取景，按住红色按钮录制（或点一下开始、再点一下结束），可预览、重录、发送；聊天中显示为圆形视频。

| 设置项 | 默认 | 说明 |
|---|---|---|
| `chat.videoMaxMb` | 50 | 视频最大 MB（不超过服务器单次上传上限 64 MB）（公开） |
| `upload.videoMaxMb` | 50 | 平台视频上传上限 |
| `chat.videoAutoplaySeconds` | 30 | 多少秒以内的视频静音自动播放，0 = 不自动播放（公开） |
| `chat.voiceMaxSeconds` | 60 | 也作为视频消息的最长时长 |

## 十一、服务端接口（新增）

所有接口都要求登录，并校验用户是该消息 / 会话的成员；写操作使用 `write` 限流策略。

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/chats/{chatId}/messages` | 新增类型 `video`、`album`，字段 `caption`、`mentions`、`silent`、`round`、`quote`（任何类型），`scheduleAt`（定时发送）；文件必须是自己上传的，大小和类型取自服务器记录 |
| PATCH | `/api/messages/{id}` | 编辑 `{ text }` 或 `{ caption }` |
| POST | `/api/messages/{id}/react` | `{ emoji }` 添加 / 取消回应 |
| GET | `/api/messages/{id}/reactions?emoji=&page=&size=` | 回应人列表（分页） |
| GET | `/api/messages/{id}/reads?page=&size=` | 私聊：已读时间；群聊：已读成员（分页） |
| POST | `/api/messages/{id}/pin` | `{ pin: true/false }` |
| POST | `/api/messages/forward` | `{ ids: [...], to: [chatId...] }` 批量按顺序转发（最多 100 条到 20 个聊天） |
| POST | `/api/chats/{chatId}/delete` | `{ ids: [...], everyone }` 仅为我删除 / 双向删除 |
| POST | `/api/chats/{chatId}/auto-delete` | `{ seconds }`，0 = 关闭 |
| GET | `/api/chats/{chatId}/scheduled` | 我的定时消息 |
| DELETE | `/api/scheduled/{id}` | 取消定时消息 |
| POST | `/api/scheduled/{id}/send` | 立即发送 |
| GET/HEAD | `/api/media/{id}` | 支持 Range（206）、ETag，分段读取 |

实时事件（SignalR `/hubs/app`）：`chat:message`、`chat:update`（编辑）、`chat:reactions`、`chat:deleted`、`chat:meta`（置顶、计时器、定时消息数量）、`chat:read`（私聊和小群）、`chat:hidden`、`chat:typing`。

状态键：`messages`、`chatReads`、`chatPeerReads`（群聊为其他成员最新的已读时间）、`chatMeta`（`{ chatId: { pins, autoDelete, scheduled } }`）。

## 十二、数据库（迁移 0302_chat_telegram.sql，只新增）

- `Messages` 新增 `EditedAt`、`DeletedAt`、`DeletedBy`、`ExpiresAt`（到期索引）。
- `Conversations` 新增 `AutoDeleteSeconds`、`AutoDeleteBy`、`AutoDeleteAt`。
- `ChatStates` 新增 `ReactNoticeAt`（回应通知限频），新增按会话的已读索引。
- 新表：`MessageReactions`、`MessagePins`、`ChatReadLog`（每条消息的已读时间，保留 180 天）、`MessageMedia`（转发副本共用文件）、`ScheduledMessages`。

## 十三、后台

- **系统配置**：“聊天功能（表情回应、删除、定时、相册、视频）”分组包含上面所有 `chat.*` 新设置；“上传限制”分组新增 `upload.videoMaxMb`。
- **客服工作台**：消息列表显示表情回应、“已编辑”、“已删除 时间”（删除线）、“时间 自动删除”、转发来源，相册以缩略图网格显示，视频可直接播放。

## 十四、离线演示模式

- 可用：长按菜单、表情回应、编辑、置顶、多选（转发 / 删除）、相册、文件、视频、视频消息、左滑回复、@提及、草稿；“同时为对方删除”即旧版撤回。
