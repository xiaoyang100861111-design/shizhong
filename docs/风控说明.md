# 账号风控与蓝V说明

后台位置：**风控中心**（风控总览 / 风控策略 / 风控记录 / 黑白名单 / 蓝V认证）。系统配置里的「账号风控」「蓝V认证」分组是通用参数。

## 风控等级

- **关闭**：不做任何频率限制和滑块验证（黑名单仍然生效）。只建议内测时使用。
- **轻度（默认）**：正常用户基本感觉不到：只在明显异常时要求滑块，上限很宽。
- **中度**：注册每次滑块，新账号 24 小时内限制加人加群，只能拉好友进群。
- **重度**：被刷号、被骚扰时使用：新账号 3 天保护期，上限收紧，反复触发自动禁言。
- **严重**：紧急封锁：所有敏感操作都要滑块，新账号 7 天内几乎不能加人，违规 5 次即禁言 3 天。
- **自定义**：按你自己设置的每一项规则执行。

默认是 **轻度**。被刷号或被骚扰时，在后台一键切到「重度」或「严重」，立即生效，不用重启。也可以选「自定义」，每一项自己调。

## 每个等级的具体规则

数字 0 表示「不限」或「不按此条件」（「新账号每天最多…」为 0 表示保护期内禁止）。

## 滑块验证

- 自研滑块拼图，不依赖第三方服务。服务器随机画背景图并挖出拼图块，答案只在服务器上。
- 除了位置，还会检查拖动轨迹（时长、采样点、速度变化），直接调接口或匀速拖动的脚本过不了。
- 一个验证码只能试一次。通过后得到一次性令牌，只能用于对应的操作，默认 120 秒内有效（系统配置可改）。
- App 端自动处理：接口要求验证时自动弹出滑块，通过后自动重试原来的操作，每个页面都不用单独写。

## 黑白名单

- 可以按 **IP、设备、手机号、邮箱、邮箱域名、昵称关键词** 封禁，可设有效期。
- 白名单（IP、设备、手机号、邮箱）完全不受风控限制，适合公司内网、测试机。
- 同一 IP 登录失败太多次会被**自动**封禁（来源显示「自动」），到期自动解除；后台「解除登录锁定」可以手动解。

## 自动处罚

- 中度及以上：24 小时内被拦截达到设定次数，自动禁言（不能发动态、打招呼、加好友、建群、拉人）。

## 蓝V认证

- **手动认证**：后台给任意会员（包括运营人物、商家老板）加蓝V，并填写认证名称（如「官方认证」「商家认证」）。
- **域名认证**：添加邮箱域名（如 `yourcompany.com`），之后用这个域名邮箱注册的账号自动成为蓝V；也可以一键认证已经注册的账号。
- 蓝V在 App 里显示蓝色认证标识（颜色、默认名称可在系统配置里改）。
- 蓝V不受任何风控限制：不用滑块、没有加人/加群/拉人次数限制，拉人也不限于好友。
  - 例外：管理员手动封号，以及对其 IP、设备的封禁，仍然有效。
  - 同一 IP 暴力试密码的自动封禁仍然生效，用来保护蓝V账号不被盗。

## 风控记录

- 每次要求滑块、拦截、锁定、禁言、滑块失败都会记录：场景、规则、会员/账号、IP、设备、平台。支持筛选和导出，默认保留 90 天。
- 会员详情页有「风控」标签页：蓝V、禁言、登录剩余次数、近 24 小时操作次数、风控记录。
