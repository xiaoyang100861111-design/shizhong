# 盛世华章图片来源与使用说明

本目录的 `oriental-*.png` 共 24 张，是适中 H5 项目根据本系列原创构思和提示词使用 AI 工具生成的**静态透明 PNG**。题材包括宫灯、折扇、青花、金龙、四灵、科举与十二时辰等中国文化视觉元素。图片按项目网页展示尺寸优化，保留透明背景，供虚构礼物商城、直播及一对一聊天界面演示。

动画效果由产品本地 `oriental-effects.js`、`oriental-effects.css` 使用 CSS 和 Canvas 绘制、编排，叠加静态图片产生立体视觉。目录中没有可旋转的真实 3D 模型、视频或抖音官方动效包；这些图片与动效也不表示与抖音或其他平台存在授权合作。

网站发布包只包含本目录的 24 张优化图片和本说明。未裁切的生成原图保存在开发工作目录 `E:/python/msuupay/work/shizhong-oriental/raw/`，并单独打包为产品目录中的 `盛世华章-24款原图与动效源码.zip`，不随网站部署。产品中其余礼物图片、直播礼物图标、真人照片及地名数据有各自的来源与许可文件，应按原说明分别核对。

本系列仅用于本项目演示。若改作其他产品、商标或商业宣传，请单独审查使用场景与适用规则。
